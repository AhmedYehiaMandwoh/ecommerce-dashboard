# حالة نسخة الاختبار الحالية

الطلب الحالي هو سورس كامل للتجربة غير المباشرة، وليس إطلاقًا لعملاء حقيقيين. بيانات Twilio فارغة. في بيئة التطوير فقط OTP_MODE=static-test والكود123456. لا يتم إرسال رسائل ولا تحصيل مبالغ. السيرفر يرفض الكود الثابت في production. لا يوجد APK أو نشر سيرفر ضمن التسليم المطلوب الآن.

اقرأ SETUP.md وENVIRONMENT.md للتشغيل، وAPI.md للمسارات الحالية، وVERIFICATION.md لحدود الاختبار، وROADMAP.md لما تبقى. أي وصف قديم أدناه لا يتقدم على هذه الحالة الحالية.

# غيار: أول مرحلة تنفيذ متصلة

دي نسخة كود قابلة للتشغيل والتجربة، مش المشروع النهائي الجاهز للإطلاق.

## الموجود

- موقع Nuxt فيه عرض المنتجات والسلة وطلب تجريبي.
- لوحة تاجر تشوف طلباته وتغيّر حالتها وتحدّث السعر والمخزون.
- لوحة إدارة لاعتماد المتاجر والمنتجات وتفعيل حساب تاجر.
- باك إند NestJS مع Prisma ومخطط MySQL وترحيلات قاعدة البيانات.
- تطبيق React Native باستخدام Expo مربوط بنفس الـ API.
- تسجيل بالبريد وكلمة مرور، عناوين وعربيات، واستيراد CSV مبدئي لعروض أصناف موجودة.

## حدود المرحلة دي

- الطلبات والدفع والتوصيل كلها تجربة، ومفيش تحصيل فلوس.
- تسجيل الموبايل بـ OTP لسه مش متوصل.
- مفيش APK متبني أو متجرب على جهاز حقيقي لحد دلوقتي. موجود كود التطبيق وإعدادات وخطوات البناء.
- الاستيراد الحالي لحد ١٠٠٠ صف في الدفعة، مش تكامل نهائي مع برنامج التاجر أو اختبار لـ ٥٠ ألف صنف.
- اختيار العربية مش معناه إن كل قطعة متوافقة معاها. بيانات التوافق محتاجة مصدر ومراجعة.
- السلة الحالية لمحل واحد في الطلب؛ تقسيم طلب على أكتر من محل لسه محتاج تنفيذ.
- الصور والأسعار والأسماء أمثلة، مش مخزون حقيقي ولا حقوق صور شركات معتمدة.
- كل الحالات والشاشات التفصيلية في التصورات الأولى لسه مش متنفذة.

## التشغيل

ابدأ بملف `docs/SETUP.md`، وبعده `docs/ANDROID.md` للموبايل و`docs/DEPLOYMENT.md` للسيرفر.

لازم تتظبط قاعدة البيانات وعناوين الـ API والمتغيرات السرية عندك. مفيش كلمات مرور جاهزة جوه المشروع. متبعتش كلمات المرور في محادثة، ومتضيفهاش للكود.

نتايج الاختبارات وحدودها في `docs/VERIFICATION.md`، وباقي الشغل في `docs/ROADMAP.md`.
